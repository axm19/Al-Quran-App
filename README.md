📖 Al-Quran Al-Kareem Web App

A modern, responsive Quran reading application built with vanilla JavaScript and the Quran.com API.

🚀 Features
Live Search: Filter Surahs by name or number instantly.
Reading Mode: Clean UI for reading verses with English translations.
Dynamic Bismillah: Automatically displays Bismillah text for all Surahs (except At-Tawbah).
Responsive Design: Optimized for both desktop and mobile viewing.

🛠️ Tech Stack
HTML5/CSS3 (Custom Dark Mode UI)
JavaScript (ES6+)
Quran.com API V4
Google Fonts
